question: "Puis-je importer mes relevés bancaires depuis un fichier ?"
answer: "Oui, Mr Wallet accepte l'import de fichiers CSV, TSV, XLSX et XLS jusqu'à 10 Mo. L'encodage, le séparateur et le format de date sont détectés automatiquement, et chaque ligne est comparée aux transactions existantes pour éviter les doublons avant tout enregistrement. Rien n'est écrit tant que vous n'avez pas validé l'aperçu."
order: 3
---

Le mapping des colonnes de votre fichier vers les champs d'une transaction (date, montant,
libellé, catégorie) peut être sauvegardé comme modèle réutilisable, pour que le deuxième import
depuis la même banque soit immédiat. Aucune connexion directe à votre banque n'est requise ni
proposée : c'est vous qui exportez le fichier depuis votre espace bancaire.
